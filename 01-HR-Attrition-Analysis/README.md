# HR Attrition Analysis

## Project Overview
This project analyzes employee attrition data to identify patterns and factors associated with employee turnover.

## Tools Used
- Excel
- SQL
- Power BI

## SQL Analysis

SQL was used to analyze employee attrition data and answer business-related questions.

### Key SQL Analysis
- Total number of employees
- Total employees who left the organization
- Overall attrition rate
- Attrition by department
- Attrition by job role
- Attrition by gender
- Attrition by age group
- Attrition by job satisfaction
- Attrition by business travel
- Department-wise employee count and attrition
  
## Key Analysis
- Employee Attrition Rate
- Attrition by Age Group
- Attrition by Department
- Attrition by Job Role
- Attrition by Gender
- Attrition by Job Satisfaction
- Attrition by Education
- Attrition by Business Travel

## Dashboard
The Power BI dashboard provides interactive insights into employee attrition and workforce trends.
