# Financial Performance Analysis

## Project Overview
This project analyzes financial performance to understand revenue, expenses, budget performance, profit, and regional business performance.

## Tools Used
- Excel
- Power BI

## Key Analysis
- Total Revenue
- Total Budget Revenue
- Total Expenses
- Total Budget Expenses
- Total Profit
- Revenue by Region
- Revenue by Product
- Revenue by Department
- Actual Expenses vs Budget Expenses
- Actual Revenue vs Budget Revenue

## Power BI Dashboard
The dashboard provides interactive insights into financial performance, revenue, expenses, budget comparison, and profitability.

## Skills Demonstrated
- Data Cleaning
- Excel Analysis
- Data Analysis
- Data Visualization
- Power BI Dashboard Development
- KPI Reporting
- Business Insights
