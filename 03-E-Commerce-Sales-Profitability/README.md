# E-Commerce Sales & Profitability Analysis

## Project Overview
This project analyzes e-commerce sales and profitability to understand business performance across products, categories, cities, regions, order status, and payment modes.

## Tools Used
- Excel
- Power BI

## Key Analysis
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Total Quantity
- Sales by Category
- Profit by Category
- Sales by City
- Sales by Payment Mode
- Analysis by Region
- Analysis by Order Status

## Power BI Dashboard
The dashboard provides interactive insights into e-commerce sales, profitability, product categories, cities, payment modes, regions, and order status.

## Skills Demonstrated
- Data Cleaning
- Excel Analysis
- Data Analysis
- Data Visualization
- Power BI Dashboard Development
- KPI Reporting
- Business Insights
